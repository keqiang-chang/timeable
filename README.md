# 我的课表 · 使用说明

课表 + AI 法学助手 + 每日案例与法律英语。武汉大学 2026-2027学年 第一学期，常克强（2026281060070）。

## 应用里有什么

底部四个标签：

| 标签 | 内容 |
|---|---|
| **课表** | 周视图网格 / 按天列表、今天的课、同一时段冲突提示、课前提醒、导出日历 |
| **助手** | 和 DeepSeek 对话，流式输出，多会话，对话记录存在本机 |
| **每日** | 每天自动按当天课程生成一个教学案例 + 案例分析，以及 5 个法律英语词汇；当天只生成一次，可以往前翻看 |
| **我的** | API Key、模型、锁屏密码、周次基准、提醒设置、主题、数据清理 |

另外有**启动锁屏**：设置 4-6 位数字密码后，每次打开应用要先解锁（后台超过 5 分钟回来也会重新锁）。

## 配置 DeepSeek（用 AI 功能必须做）

AI 助手和每日内容都要用 DeepSeek 的接口，**需要你自己申请一个 API Key**：

1. 电脑浏览器打开 [platform.deepseek.com](https://platform.deepseek.com)，注册并登录。
2. 先在「充值」里充一点钱（最低 10 元左右）。DeepSeek 按用量计费，没有免费额度。
3. 左侧打开 **API Keys** → **创建 API Key** → 复制那串 `sk-` 开头的字符（**只显示一次，先存起来**）。
4. 打开手机上的「我的课表」→ 底部 **我的** → 把 Key 粘到「DeepSeek API Key」里，点旁边的空白处让它保存。
5. 点 **测试连接**，显示「连接正常」就成了。

**要花多少钱？** 每天生成一次案例+词汇、偶尔聊几句，一个月大概几块钱。具体单价以 DeepSeek 官网为准。

**安全说明：**

- Key 只存在你这台手机的浏览器里，**不会上传到任何地方**，也不会写在代码里。
- 我已经实测过 DeepSeek 允许网页直接调用（CORS 通过），所以不需要额外搭服务器。
- 唯一的风险是：如果别人拿到你的手机并且会用开发者工具，理论上能看到这个 Key。真介意的话，到平台把 Key 删掉换一个即可。

## 装到安卓手机上（推荐）

托管到 GitHub Pages 后，在手机上「添加到主屏幕」，就是一个全屏、离线可用的 App——
不需要应用商店、不需要开发者账号、不需要付费。

完整步骤写在 [`装到手机上.md`](装到手机上.md)，大约 10 分钟，全程在浏览器里点。

**更新应用时不用改版本号**：`sw.js` 用的是「网络优先 + 后台更新」策略，
联网打开两次就会自动更新到最新版本。

**注意**：AI 功能需要联网。断网时课表、历史对话、已经生成过的每日内容照常能看，
但发不了新消息、生成不了新内容。

## 打开网页

电脑：双击 `index.html`。

手机：把 `index.html` 通过微信/QQ/邮件发到手机，用手机浏览器打开（Safari、Chrome、夸克都行）。窄屏打开时默认就是「按天」列表，比横着划表格好用，也可以切回「周表」。

网页里能做什么：

- 周视图网格，周一到周日横排、13 个小节竖排，每门课一个颜色
- 同一时段有多门课时**并排或叠放**显示，不会叠字；颜色浅的那门是本周不上课的
- 表格里被学校系统拆成两段的课会自动并成一个整块
- **旁听课用虚线框 + 「旁听」角标**标出，和本专业课程区分
- 同一时段撞课会**自动弹出冲突提示**，列出重叠的课程、周次和教室
- 打开自动定位到本周，高亮今天那一列和此刻正在上的课
- 顶部「今天的课」按时间列出今天的课，标注「正在上 / 即将开始 / 已结束」
- 点任意一节课看详情：课程名、教学班、时间、周次、教室、教师
- 左右箭头或下拉框切换周次；当前周不是本周时会提示本周是第几周
- 浅色 / 深色 / 跟随系统

## 导入日历（推荐，最靠谱的提醒方式）

导入一次，整个学期的课都在日历里，不用网页开着。

**iPhone / iPad**：把 `课表.ics` 发到手机（微信「文件传输助手」也行）→ 点开文件 → 「添加到日历」。导入后在「日历」App 里能看到全部课程，每节课默认课前 15 分钟提醒。

**Android**：把 `课表.ics` 传到手机 → 点击文件 → 选择用「日历」打开并导入。不同品牌入口略有差异，小米/华为也可以走「日历 → 设置 → 导入」。

**电脑**：Windows 日历 / Outlook 直接双击 `课表.ics` 即可导入；Google 日历网页版走「设置 → 导入和导出 → 导入」。

日历里一共 125 个事件，按周次逐个展开，不上课的周次会自动跳过。比如「论文写作指导」只在 5-8 周出现（10/10、10/17、10/24、10/31），其余周六是空的。

## 旁听课（3 门，可选）

你标注的三门课按旁听处理，都不在学校导出的课表里：

| 课程 | 教师 | 周次 | 时间 | 教室 |
|---|---|---|---|---|
| 民法总论专题 | 扬巍 | 3-10周 | 周二 6-9节 | 法326 |
| 中国刑法总论 | 陈家林、李颖峰 | 3-10周 | 周二 6-9节 | 法329 |
| 民事诉讼法专题 | 占善刚、刘学在 | 3-10周 | **周三** 6-9节 | 法221 |

⚠️ **有两处冲突，一个在周二、一个在周三。**

**周二 6-9 节（3-10 周）**：民法总论专题（法326）和中国刑法总论（法329）时间完全相同，而且都和你自己的「思想政治理论课（硕士1）」撞车（周二 6-8 节，1-11 周，文理学部 1区枫-206）。这三门只能选一门，想旁听任何一门都要占用思政课的时间。

**周三 6-9 节（3-10 周）**：民事诉讼法专题（法221）和你必修的「法理学概论」完全重叠（信息学部 3区1-303）。想听这门就得占用法理学概论的时间。

第 1、2 周没有冲突，第 11 周之后旁听课也都结课了。

网页上切到第 3-10 周任意一周，表格上方会自动弹出这条冲突提示。日历方面：

- `课表.ics` **不含**旁听课，导入它不会有额外提醒，不影响正常课表。
- 决定去旁听后，再把 `旁听课.ics` 导入手机，单独成一份日历，不想听了直接删掉整份就行。
- 网页里点「导出日历」默认也只导出本专业课程；如果想合并导出，到「设置」里勾上「导出日历时包含旁听课」。

## 两种提醒方式的区别

| | 网页内提醒 | 日历文件（.ics） |
|---|---|---|
| 怎么触发 | 页面打开时，课前 15 分钟弹横幅 + 浏览器通知 | 手机系统日历自己提醒 |
| 网页关掉后 | ❌ 失效 | ✅ 照常提醒 |
| 手机后台 | ⚠️ 浏览器会被系统冻结，常常不触发 | ✅ 稳定 |
| 依赖 | 页面一直开着，且点了「开启浏览器通知」 | 只需要导入一次 |

结论：**要让提醒靠谱，就用日历文件。** 网页内提醒当作打开网页时的辅助提示。用 `file://` 直接打开网页时，部分浏览器会拒绝发系统通知，这时页面内的横幅提醒仍然有效。

## 设置

点网页右上角「设置」：

- **第 1 周的周一**：所有周次和日期都按这个基准推算。默认 2026-09-07。
- **提前多少分钟提醒**：默认 15 分钟，改完立即生效。
- **外观**：浅色 / 深色 / 跟随系统。
- **开启浏览器通知**：申请系统通知权限。另有「预览一节提醒」可以看提醒长什么样。

设置只存在打开网页的那台设备的浏览器里。

⚠️ **改了「第 1 周的周一」之后，要重新点「导出日历」并重新导入**，因为 `课表.ics` 里的日期是按那个基准算出来的。
