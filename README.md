## 装到安卓手机上（推荐）

现在这个网页已经是一个完整的 PWA：**托管到 GitHub Pages 后，在手机上「添加到主屏幕」，
就是一个全屏、离线可用的 App**，不需要应用商店、不需要开发者账号、不需要付费。

完整步骤写在 [`装到手机上.md`](装到手机上.md)，大约 10 分钟，全程在浏览器里点。

已经实测通过的：service worker 正常注册并激活、7 个资源全部预缓存，
**断网后重新打开页面仍能完整渲染**（18 个课程块、今天的课、冲突提示都在）。

⚠️ 要更新应用内容时，改完 `index.html` 必须把 `sw.js` 里的 `CACHE` 版本号加一，
否则手机会一直读缓存里的旧版本。

## 打开网页

电脑：双击 `index.html`。

手机：把 `index.html` 通过微信/QQ/邮件发到手机，用手机浏览器打开（Safari、Chrome、夸克都行）。窄屏打开时默认就是「按天」列表，比横着划表格好用，也可以切回「周表」。

网页里能做什么：

- 周视图网格，周一到周日横排、13 个小节竖排，每门课一个颜色
- 同一时段有多门课时**并排或叠放**显示，不会叠字；颜色浅的那门是本周不上课的
- 表格里被学校系统拆成两段的课会自动并成一个整块
- **旁听课用虚线框 + 「旁听」角标**标出，和本专业课程区分
- 同一时段撞课会**自动弹出冲突提示**，列出重叠的课程、周次和教室
- 打开自动定位到本周，高亮今天那一列和此刻正在上的课
- 顶部「今天的课」按时间列出今天的课，标注「正在上 / 即将开始 / 已结束」
- 点任意一节课看详情：课程名、教学班、时间、周次、教室、教师
- 左右箭头或下拉框切换周次；当前周不是本周时会提示本周是第几周
- 浅色 / 深色 / 跟随系统

## 导入日历（推荐，最靠谱的提醒方式）

导入一次，整个学期的课都在日历里，不用网页开着。

**iPhone / iPad**：把 `课表.ics` 发到手机（微信「文件传输助手」也行）→ 点开文件 → 「添加到日历」。导入后在「日历」App 里能看到全部课程，每节课默认课前 15 分钟提醒。

**Android**：把 `课表.ics` 传到手机 → 点击文件 → 选择用「日历」打开并导入。不同品牌入口略有差异，小米/华为也可以走「日历 → 设置 → 导入」。

**电脑**：Windows 日历 / Outlook 直接双击 `课表.ics` 即可导入；Google 日历网页版走「设置 → 导入和导出 → 导入」。

日历里一共 125 个事件，按周次逐个展开，不上课的周次会自动跳过。比如「论文写作指导」只在 5-8 周出现（10/10、10/17、10/24、10/31），其余周六是空的。

网页上切到第 3-10 周任意一周，表格上方会自动弹出这条冲突提示。日历方面：

- `课表.ics` **不含**旁听课，导入它不会有额外提醒，不影响正常课表。
- 决定去旁听后，再把 `旁听课.ics` 导入手机，单独成一份日历，不想听了直接删掉整份就行。
- 网页里点「导出日历」默认也只导出本专业课程；如果想合并导出，到「设置」里勾上「导出日历时包含旁听课」。

## 两种提醒方式的区别

| | 网页内提醒 | 日历文件（.ics） |
|---|---|---|
| 怎么触发 | 页面打开时，课前 15 分钟弹横幅 + 浏览器通知 | 手机系统日历自己提醒 |
| 网页关掉后 | ❌ 失效 | ✅ 照常提醒 |
| 手机后台 | ⚠️ 浏览器会被系统冻结，常常不触发 | ✅ 稳定 |
| 依赖 | 页面一直开着，且点了「开启浏览器通知」 | 只需要导入一次 |

结论：**要让提醒靠谱，就用日历文件。** 网页内提醒当作打开网页时的辅助提示。用 `file://` 直接打开网页时，部分浏览器会拒绝发系统通知，这时页面内的横幅提醒仍然有效。

## 设置

点网页右上角「设置」：

- **第 1 周的周一**：所有周次和日期都按这个基准推算。默认 2026-09-07。
- **提前多少分钟提醒**：默认 15 分钟，改完立即生效。
- **外观**：浅色 / 深色 / 跟随系统。
- **开启浏览器通知**：申请系统通知权限。另有「预览一节提醒」可以看提醒长什么样。

设置只存在打开网页的那台设备的浏览器里。

⚠️ **改了「第 1 周的周一」之后，要重新点「导出日历」并重新导入**，因为 `课表.ics` 里的日期是按那个基准算出来的。
